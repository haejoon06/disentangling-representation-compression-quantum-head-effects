# Disentangling Representation Compression and Quantum-Head Effects

This repository contains the reproducibility package for **Disentangling Representation Compression and Quantum-Head Effects in Multi-Domain Quantum Transfer Learning**.

The benchmark uses frozen DINOv2 ViT-S/14 representations on CIFAR-10, EuroSAT RGB, and PathMNIST. Four six-dimensional reducers (PCA, LDA, NCA, and supervised projection) are crossed with Logistic Regression, RBF-SVM, an exactly parameter-matched MLP, and a six-qubit VQC over ten seeds. Full-space 384D classical references quantify the compression penalty.

## Reproducible execution

The Windows launcher calls the existing environment directly:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\launch_article09.ps1 -Stage all -Resume
```

The launcher starts a hidden process and returns immediately. It writes the PID to `state/pipeline.pid`, logs to `logs/`, and terminal sentinels to `state/SUCCESS` or `state/FAILED`. It never polls the process.

To inspect status only when requested:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\status_article09.ps1
```

Power loss recovery uses:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\launch_article09.ps1 -Stage all -Resume
```

Completed tasks are skipped. Neural reducers, MLPs, and VQCs save an epoch checkpoint. Classical estimators are task-checkpointed and only the interrupted task is repeated.

## Stages

```text
setup -> data -> audit -> embeddings -> backend -> pilot -> freeze
      -> final -> test -> report -> notebook -> article
```

Training and hyperparameter selection only read train and validation manifests. Test labels are loaded by the separate `test` stage after `frozen/protocol_v1.json` exists and its hash is verified.

## Main outputs

- `notebooks/Article09_Reproducible_Research.ipynb`: complete executable analysis notebook; the report stage executes it and stores outputs in place.
- `results/figures/`: every manuscript figure generated by the notebook.
- `results/tables/`: manuscript tables reconstructed from raw run artefacts.
- `article/Article09_QMI_Submission.docx`: author-identified, two-column submission manuscript.
- `models/Article09_Models.zip`: trained reducers and model states for repository release.

## Principal results

Validation-only model selection produced mean test macro-F1 scores of 0.946 on CIFAR-10, 0.886 on EuroSAT RGB, and 0.795 on PathMNIST for the best classical configurations. The strongest six-qubit VQC configurations reached 0.856, 0.752, and 0.651, respectively. All final comparisons use ten matched seeds, paired inference, locked test partitions, and calibration diagnostics. The statevector results do not claim quantum advantage or speedup.
